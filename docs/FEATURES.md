# 功能完成度

状态定义：

- **完成**：真实业务逻辑 + 自动化测试覆盖（或已在真实程序中逐项验证）。
- **部分**：可用，但受音源/系统限制，或只覆盖常见场景。
- **受限**：功能路径存在，但依赖外部服务可用性，失败时给出明确提示。
- **未实现**：本轮没有做，代码中也没有假实现。

## 第三轮（v1.0.12）能力补充

- **在线音源播放找回**：单源解析失败时先做音质递进（standard → higher → 320k），再按

- **品牌标志**：界面使用原版矢量标志（深/浅两套），应用图标/托盘/EXE 使用原版多尺寸 `.ico`。
