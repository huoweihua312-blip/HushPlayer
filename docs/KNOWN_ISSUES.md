# 已知问题与限制

本文件只记录**当前真实存在**的问题，按影响分级。已修复的问题见 [TEST_REPORT.md](TEST_REPORT.md) 第 4 节与 git 历史。

## A. 功能限制（设计如此）

1. **在线音源能力不一致。** 音源由第三方 MusicFree 兼容插件提供，实测（2026-10-18，本机）：
   - 网易云：搜索 / 播放 / 歌词可用；`resolveDownload` 返回 `false`，因此**不支持下载**。
   - 酷我：搜索 / 播放 / 下载可用；部分歌曲 `getLyric` 报 `Cannot read properties of null (reading 'lrclist')`，界面回退到 LRCLIB 或显示「暂无歌词」。
   - 酷狗：搜索 / 歌词可用，`resolvePlayback` 返回 404，播放**当前不可用**。
   - QQ 音乐：搜索返回 0 条；QQ（海棠）搜索有结果但播放 404，**不可用**。
   - 汽水：搜索 / 播放 / 下载可用，部分歌曲无歌词。
   - 小米：搜索直接抛错，**不可用**。
   界面按真实 capability 显示能力，不会假装可播放。
2. **跨音源回退有上限。** 播放失败时最多尝试 2 个其他可播放音源，匹配阈值基于标题/歌手/时长；冷门歌曲可能匹配不到，此时给出「无法播放」提示。
3. **更新检查只提示不安装。** 配置 `update.manifest_url` 后可检测新版本并打开下载页；没有静默下载或自动安装。用户明确要求不引入 Velopack，本实现以可靠、可维护为先。
4. **SMTC 依赖 `winrt` 组件。** 已接入 Windows 系统媒体控制（媒体面板/锁屏显示曲目并可控制）；若 `winsdk`/`winrt` 导入失败或系统版本不支持，会静默降级为仅键盘媒体键，不影响播放。
5. **任务栏进度条按系统支持降级。** 通过 `ITaskbarList3` 设置进度；部分系统/环境返回 `E_NOINTERFACE`（本机即如此），此时静默不显示，不影响播放。
6. **下载只在有 `download` 能力的音源可用。** 下载目录默认 `%USERPROFILE%\Music\HushPlayer Downloads`，不可写时回退到应用数据目录下的 `Downloads`。
7. **桌面歌词的鼠标穿透使用 Win32 扩展样式。** 在 Windows 10/11 上有效；设置改变后需要重新显示一次窗口才能完全生效（已尽量即时应用）。

## B. 体验问题（已知但未修完）

1. **正式 Logo 为单一深色版本。** 已接入用户提供的 `assets/brand/HushPlayer.ico`（渲染出 `logo.png`），窗口/托盘/侧栏/关于/打包全部使用；目前没有浅色专用或深色专用变体，若后续提供 `logo_light.png` / `logo_dark.png`，重启即自动替换（规范见 `assets/brand/README.md`）。
2. **内置 MiSans 字体需要遵守小米字体许可。** 字体仅作应用私有嵌入，不安装到系统、不修改、不单独分发；`assets/fonts/MiSans-NOTICE.md` 与许可 PDF 随包提供。
1. **在线搜索耗时长。** 首次搜索需启动 Node 运行时并并行查询多个音源，通常 2–6 秒；界面有加载提示，但暂无逐音源进度条。
3. **部分在线结果缺时长**（酷我、部分 QQ 结果 `duration` 为空），列表显示 `—`。这是插件返回数据缺失，不做估算。
3. **极长歌名在窄窗口里会被省略**，符合预期，但省略位置目前是尾部省略，未做中间省略。
4. **大型音乐库（>2 万首）仍未实测。** 列表采用整库装模型 + 内存排序，设计上支持数千首流畅浏览；1.1.0 增加了 20 分钟循环 soak（播放/切页/沉浸/主题）记录内存与句柄，见 `TEST_REPORT.md` 第 7 节。
5. **音量曲线使用对数映射**，与系统音量不完全线性对应，主观上更平滑，但不同设备可能有体感差异。
6. **切歌瞬间的封面过渡在极慢机器上可能掉帧**（220ms 交叉淡入），已通过「减少动画」设置关闭。

## C. 兼容性与环境

1. 需要 **Windows 10 1809+ / Windows 11**，x64。未提供 ARM64 版本。
2. 高 DPI 已启用 Per-Monitor V2；在混合 DPI 的多显示器之间拖动时，Qt 会重建部分绘制资源，可能有短暂重绘闪烁。
3. 安装包为解压即用的 onedir 目录（zip），未提供 MSI/EXE 安装向导，因此没有「程序和功能」里的卸载项；删除目录即卸载，用户数据保存在单独的数据目录中。
4. **开发环境的数据目录回退**：本机 venv 进程无权在 `%LOCALAPPDATA%` 建目录时，会回退到项目内 `Data/`（日志里会写明最终路径）。正式安装包在普通用户环境下使用 `%LOCALAPPDATA%\HushPlayerReimagined`。
5. 首次启动会在内置 Node 运行时上加载插件，若安全软件拦截子进程启动，在线功能会提示「在线音源运行器启动失败」，本地播放不受影响。

## D. 未实现（明确不在本次范围）

- 自动更新下载/安装、增量更新。
- 音源插件市场/在线安装界面（当前读取 `source_registry.json` 与用户插件目录）。
- Last.fm / 听歌统计报表、音频可视化、均衡器。
- 歌词编辑器（仅支持偏移校准与本地文件绑定）。
- 移动端/网页端同步。

发现新问题时，请附上 `%LOCALAPPDATA%\HushPlayerReimagined\logs\hushplayer.log` 与复现步骤。


## 第三轮补充（v1.0.3）

- **酷狗 / QQ海棠**：插件调用的第三方接口当前返回 404（在 runtime 目录直接调用 `plugin_host.js` 同样 404），
  无法在本项目内修复；播放时会自动到其它音源找回同一首歌，并在状态栏标明实际来源。
- **小米**：搜索接口返回结构变化导致插件抛 `Cannot read properties of undefined (reading 'map')`，同样依赖插件更新。
- **跨源回退的边界**：若所有音源都没有匹配度 ≥55 的候选，会提示「其他音源没有找到同一首歌」并停止；
  不会随便播放一个不相干的版本。
