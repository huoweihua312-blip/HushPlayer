# Velopack 可选安装目录设计

## 背景

当前 Velopack 安装包默认使用当前用户的 `%LOCALAPPDATA%\HushPlayer` 目录。该位置不需要管理员权限，更新可靠，但会持续占用系统盘空间。用户希望首次安装时能够选择其他本地磁盘，同时保持后续应用内更新、快捷方式和回滚行为正常。

## 目标

- 正式安装器首次运行时允许用户选择本地磁盘上的安装目录。
- 安装完成后，更新始终沿用已经选择的安装根目录。
- 保留 Velopack 的 `current`、`packages`、`Update.exe` 目录结构。
- 不移动或修改 `%APPDATA%\HushPlayer` 下的用户数据。
- 选择目录不可用时明确失败，不删除旧版本或用户数据。
- 继续支持当前 C 盘默认安装，降低普通用户操作成本。

## 方案

正式用户安装使用现有 Inno Setup 安装包，并明确保留目录选择页；Velopack 安装包继续作为并行原型，不作为需要自定义目录的正式入口。应用启动时继续通过 `Update.exe` 和 `sq.version` 识别 Velopack 测试安装；正式 Inno 安装则继续把当前可执行文件所在目录交给现有更新助手。两条路径都不通过手动移动 `current` 目录实现。

安装目录校验限制为本地、可写、非空冲突目录。网络盘、U 盘、无法创建文件的目录和正在运行的旧安装目录应被拒绝或要求用户选择其他目录。已有安装升级时优先保留原目录，不因新版本安装器的默认值改变位置。

## 兼容与回滚

- 旧版 Inno Setup 安装继续使用现有 `/DIR` 和当前安装目录回退逻辑。
- 已安装在 C 盘的 Velopack 版本不自动迁移；用户重新安装时才选择新目录。
- 安装失败时保留现有安装和用户数据。
- 如新路径逻辑出现问题，可回滚安装器参数和路径校验改动，不需要迁移 JSON 数据。

## 测试范围

- 默认 C 盘首次安装。
- D/F 盘本地目录首次安装。
- 已选择其他磁盘后检查更新、下载、退出、替换和重启。
- 关闭或删除目标磁盘目录后的失败提示与旧版本保留。
- 快捷方式目标、`Update.exe`、`current` 目录和用户数据目录不变。
- 旧版 Inno Setup 更新回退不受影响。

## 不在本轮范围

- 不迁移现有用户数据。
- 不允许网络盘或可移动磁盘作为正式安装位置。
- 不重写 Velopack 更新器。
- 不改变更新清单、版本号或发布源。
