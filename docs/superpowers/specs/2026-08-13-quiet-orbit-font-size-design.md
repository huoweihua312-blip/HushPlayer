# Quiet Orbit 字号增量设计

## 目标

解决 100% Windows 显示缩放下中文正文、歌曲列表和播放栏辅助文字偏小的问题，同时保持 900px 宽窗口可用，不改变播放、数据和在线更新行为。

## 方案

- 将 `ThemeFonts` 的正文、辅助文字、卡片文字和播放栏文字统一提高一级。
- 保留已验收的 Source Han Sans SC 字体和 Medium/Bold 字重，不新增第三方依赖。
- 让本地歌曲表和在线结果表显式使用主题正文像素字号，避免委托绘制继续使用系统默认字号。
- 播放栏仍保持 102px 总高度，只扩大歌曲信息的内部节奏；可用性提示区域同步留出空间。

## 验收重点

- 侧栏、搜索框、设置项、卡片和列表文字具有一致的可读尺度。
- 播放栏歌曲名、歌手、可用性提示和时间不被裁切。
- 900×600、1200×800 和 1600×900 窗口布局不溢出。
- 只改变视觉 token 和控件字体，不改变持久化数据、播放队列或在线更新逻辑。
