# HushPlayer UI V2 字号增量设计

## 目标

解决 100% Windows 显示缩放下中文正文、歌曲列表和播放栏辅助文字偏小的问题，同时保持 900px 宽窗口可用，不改变播放、数据和更新行为。

## 方案

- 将 `ThemeFonts` 的正文、辅助文字、卡片文字和播放栏文字统一提高一级。
- 在 UI V2 根样式上设置正文基线字号和 Medium 字重，让没有单独 QSS 的 Qt 控件也遵循同一基线。
- 让本地歌曲表和在线结果表显式使用主题正文像素字号，避免委托绘制继续使用系统默认字号。
- 播放栏仍保持 102px 总高度，仅扩大两行歌曲信息的内部节奏和时间文字；不移动运输控制区。

## 验收重点

- 侧栏、搜索框、设置项、卡片和列表文字在同一窗口内具有一致的可读尺度。
- 播放栏歌曲名、歌手、时间不被裁切。
- 900×600、1200×800 和 1600×900 窗口布局不溢出。
- 只改变视觉 token 和控件字体，不改变持久化数据、播放队列或在线更新逻辑。
