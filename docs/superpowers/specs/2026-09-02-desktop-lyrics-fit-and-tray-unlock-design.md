# 桌面歌词完整显示与托盘解锁设计

## 背景

桌面歌词当前允许字号在 22–84 px 之间调整，但窗口高度仍可保持在 90–135 px。大字号下，主歌词、副歌词、布局间距和上下边距的总高度会超过窗口可用高度，Qt 因而压缩标签并裁切文字。

当前桌面歌词在锁定状态使用 Windows 原生鼠标穿透。该状态下窗口不会收到左键或右键事件，所以不能直接通过右键歌词打开设置。解锁后虽已有右键信号链路，但播放器底栏按钮仍提供右键设置入口，容易让用户误以为只能右键按钮。快速设置窗口还使用透明顶层窗口，实际显示时背景没有可靠绘制，导致封面和底部控件透出。

## 目标

- 大字号双行歌词完整显示，不裁切顶部、底部或字形边缘。
- 字号改变时自动增加窗口高度，小字号不产生多余的大面积空白。
- 歌词切换时窗口高度保持稳定，不因每句内容不同而上下跳动或闪烁。
- 锁定时继续保持真正鼠标穿透。
- 保留歌词附近的独立悬停解锁按钮。
- 锁定时可从系统托盘可靠解锁桌面歌词。
- 解锁后直接右键桌面歌词本体打开快速设置。
- 快速设置使用清晰、不透明、符合现有 Fluent 风格的背景。

## 非目标

- 不修改播放、暂停、队列或播放上下文。
- 不修改歌词时间轴、解析、同步或翻译选择逻辑。
- 不引入全局鼠标钩子，也不让锁定歌词选择性截获右键。
- 不改变设置 JSON 结构或现有字段含义。
- 不创建第二个独立托盘图标。
- 不进行桌面歌词或托盘架构的大规模重写。

## 方案

### 1. 稳定的字体度量最低高度

桌面歌词窗口保留 `floating_lyrics_height` 作为用户设置的基础高度。应用字体后，通过 `QFontMetrics` 分别取得主歌词和副歌词的实际单行高度，并加上：

- 布局上下边距；
- 主、副歌词之间的间距；
- 少量字形安全留白，避免粗体或特定开放字体贴边；
- 桌面歌词有可显示主歌词时固定预留一行副歌词高度；副歌词暂时为空时只隐藏文字，不收缩窗口。

窗口实际高度为“基础高度”和“字体度量最低高度”中的较大值。这个最低高度只随字号和字体变化，不随每句歌词文本内容或副歌词暂时为空而反复收缩，因此不会在歌词切换时产生明显跳动。

调整高度后继续使用现有屏幕边界限制逻辑。靠近屏幕底部时，窗口整体向上限制在可用区域内，保持全部内容可见。计算出的实际高度不写回设置文件，旧设置保持兼容。

### 2. 右键歌词与锁定语义

锁定状态继续使用 `WindowTransparentForInput`，歌词主体的所有鼠标事件都穿透到下方应用。独立悬停解锁按钮保持为可点击的顶层工具按钮，不改变歌词主体的穿透状态。

解锁后，右键按下和释放都发生在桌面歌词表面时，窗口发出一次设置请求，在点击位置附近打开快速设置。打开设置时取消任何未完成拖动，避免歌词继续跟随鼠标。

播放器底栏“桌面歌词”按钮保留左键显示/关闭功能，但取消其右键快速设置入口。设置入口由“解锁后右键歌词本体”承担，避免入口含义混乱。

### 3. 系统托盘解锁入口

复用现有 HushPlayer `QSystemTrayIcon`，不增加第二个图标。现有托盘菜单增加一个按状态显示的“解锁桌面歌词”动作。

托盘图标的显示条件调整为以下任一条件成立：

- 主窗口已最小化到托盘；
- 桌面歌词已启用且处于锁定状态。

触发“解锁桌面歌词”后，由主窗口沿用现有设置保存链路将 `floating_lyrics_passthrough` 更新为 `false`。动作随即隐藏；如果主窗口并未最小化到托盘，托盘图标也恢复隐藏。如果主窗口仍在托盘中，图标继续保留，确保原关闭行为不变。

托盘控制器分别记录“主窗口隐藏到托盘”和“桌面歌词锁定”两个状态，再统一同步图标可见性，避免 `restore_window()` 误把仍用于歌词解锁的图标隐藏。

### 4. 不透明快速设置面板

快速设置仍使用无标题栏 Popup，保留圆角、边框和屏幕边缘定位。顶层透明窗口仅用于圆角边缘，面板内容区域由独立、不透明的主题表面可靠绘制：

- 背景使用当前主题的 `surface_elevated` 不透明色；
- 使用现有边框色和圆角尺寸；
- 不使用模糊、玻璃或透明叠层；
- 保留现有控件、键盘焦点、关闭按钮和错误信息行为。

面板在主窗口上方或桌面歌词旁显示时，不再透出封面、歌词或播放器控件。

## 状态与数据流

1. 桌面歌词设置变更进入现有 `SettingsSnapshot` 校验和延迟保存链路。
2. `DesktopLyricsWindow` 根据设置应用字体并计算实际最低高度。
3. 锁定状态变化由主窗口同时同步给桌面歌词窗口和托盘控制器。
4. 托盘“解锁桌面歌词”动作只发出请求，不直接修改 JSON。
5. 主窗口处理请求、保存设置并刷新窗口与托盘状态。

## 风险与保护措施

- **托盘状态冲突：** 使用两个明确布尔状态统一计算可见性，并覆盖恢复窗口、最小化、解锁和退出测试。
- **窗口越出屏幕：** 每次有效高度变化后复用已有屏幕边界限制函数。
- **高度抖动：** 不按每句实际文本高度动态缩放，只按字体和显示行数计算稳定最低高度。
- **设置兼容性：** 不新增或重写持久化字段；实际高度只存在于运行时。
- **鼠标穿透退化：** 不引入全局钩子；锁定主体继续使用原生穿透，托盘和独立按钮仅作为解锁入口。

## 验证

- 22、42、84 px 下检查实际窗口高度和标签完整空间。
- 84 px、双行歌词时验证主副歌词均不裁切。
- 切换多句歌词时验证窗口高度稳定。
- 解锁后右键歌词只打开一次设置，且不会启动或遗留拖动。
- 锁定后歌词主体继续穿透，独立按钮可解锁。
- 锁定时托盘图标和“解锁桌面歌词”动作出现；解锁后按主窗口托盘状态正确隐藏或保留。
- 最小化到托盘、恢复和退出行为保持原样。
- 快速设置背景为不透明主题表面，控件和文字可清晰辨认。
- 执行 Python 语法、UTF-8、差异检查和相关单元测试。
