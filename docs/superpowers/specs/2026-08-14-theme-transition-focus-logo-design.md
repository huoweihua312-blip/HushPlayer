# 主题切换、按钮焦点与 Logo 对比度优化设计

## 目标

- 减少 HushPlayer 在深色/浅色主题切换时的中间态重绘和明显卡顿。
- 鼠标点击按钮时不显示割裂的系统焦点外框，同时保留键盘导航的可见焦点提示。
- 让左上角 Quiet Orbit Logo 在浅色背景下使用足够深的颜色，保持完整可见。

## 范围与约束

- 仅调整 UI V2 的主题刷新、按钮交互样式和 Logo 资源选择。
- 不修改播放、歌词、队列、用户数据、持久化 JSON、更新协议或打包路径。
- 保持现有深色主题的视觉方向和 Logo 比例。

## 方案

1. 主题刷新采用一次性 UI 更新事务：暂时关闭主窗口和应用级重绘，集中更新调色板、全局样式、标题栏、侧栏、路由页面和播放器栏，完成后恢复重绘并主动刷新一次。主题切换不创建新窗口，也不重建歌曲列表。
2. 按钮焦点采用鼠标/键盘区分：鼠标点击后的按钮不保留系统外框；通过 Tab 或快捷键获得焦点时使用统一的细焦点边界。按下态只改变颜色，不改变尺寸和布局。
3. Logo 保留现有深色版本，新增浅色主题深灰版本；标题栏使用主题对应资源，兼容侧栏也同步选择，避免浅色背景下 Logo 与背景混合。

## 验证

- 主题切换前后窗口、播放器状态、当前路由和歌曲列表对象保持不变。
- 连续切换深色/浅色若干次，检查界面无明显白闪、控件错位或重复叠加。
- 鼠标点击按钮不出现割裂外框；Tab 导航仍能看到焦点提示。
- 两个主题下 Logo 均完整显示，浅色版本与背景有明显对比。
- 运行 Python 语法检查、主题切换回归测试、按钮焦点回归测试和现有 UI smoke 测试。
